# Analysis data

Monte Carlo outputs underlying the figures and tables in the paper. All are
generated by the notebooks in `../notebooks/`; they are included here so the
results can be inspected without re-running the simulations. Common parameters:
unit cube `C = [0,1]^3`, isotropic directions, two-length mixture
`{0.2, 0.4}` with equal probability, fixed seeds (`numpy.random.default_rng`).

| File | Description | Produced by |
|---|---|---|
| `normality_counts.csv` | Raw contact counts on the exhaustive counting board at `2r = 0.02`. Long format: `n`, `replicate`, `contact_count`. 8000 replicates for `n ∈ {100,200,400}`, 3500 for `n = 800` (27,500 rows). Backs Table 3 and the histogram / Q–Q / skewness figures. | `04_asymptotic_normality` |
| `truncated_moments.csv` | Cube-truncated length moments `λ₁, λ₂, Var(ℓ_C)` and `E[sin γ]`: closed form vs Monte Carlo (2×10⁵ fibers). | `01_truncated_length_moments` |
| `contact_probability_rsweep.csv` | Pairwise contact probability vs fiber radius: `r`, `q_pred`, `q_obs`, `ratio`. | `02_contact_probability_and_rsweep` |
| `variance_validation.csv` | U-statistic mean and variance at `r = 0.002`, `n = 600`: predicted vs observed. | `03_variance_validation` |
| `coverage.csv` | Empirical coverage of normal-approximation intervals (two-sided 90/95/99%, one-sided upper 95%) vs `n`. | `05_additional_experiments` |
| `ks_distance.csv` | Kolmogorov distance `d_K` of the standardized count to `N(0,1)` vs `n`, with the Monte Carlo noise floor. | `05_additional_experiments` |
| `anisotropy.csv` | Isotropic vs oblate (in-plane preferred, `c=0.5`) directions: `E[sin γ]`, mean, skewness, `d_K` at `n=400,800`. | `05_additional_experiments` |
| `timing.csv` | Wall-clock time per realization vs `n` (quadratic pair-enumeration cost). | `05_additional_experiments` |

These files are regenerated (up to Monte Carlo error, with the committed seeds)
by running the corresponding notebooks.
